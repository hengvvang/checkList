# Vim ：寄存器（Registers)

在 Vim 中，寄存器是用于存储文本、命令宏、查找模式以及系统状态的内置内存空间。Vim 的复制（Yank）、剪切/删除（Delete）、修改（Change）和粘贴（Put）操作本质上都是对寄存器的读写。

---

## 1. 语法与调用规范

在 Normal 模式与命令行模式下，访问寄存器的标准语法如下：

### 1.1 Normal 模式语法

* **指定写入/读取寄存器：**
* `"{register}` 前缀
* 语法格式：`"{register}{operator}{motion}` 或 `"{register}{action}`
* **示例：**
* `"ayy`：将当前行复制到寄存器 `a` 中。
* `"ap`：将寄存器 `a` 中的内容粘贴到光标之后。
* `"bdd`：剪切当前行并存入寄存器 `b`。





### 1.2 Insert / Command-line 模式语法

* **插入寄存器内容：**
* `<C-r>{register}`：直接插入寄存器文本（模拟手动按键输入，受缩进与映射影响）。
* `<C-r><C-r>{register}`：字面量插入（不展开控制字符，不触发自动缩进）。
* `<C-r><C-o>{register}`：字面量插入并保持原始缩进。
* **示例：**
* 插入模式下按 `Ctrl-r a`：将寄存器 `a` 的内容粘贴进光标处。





### 1.3 寄存器查看命令

* `:reg` 或 `:registers`：列出当前所有非空寄存器及其内容。
* `:reg {args}`：列出指定的一个或多个寄存器。
* **长命令：** `:registers a b 0`
* **短命令：** `:reg ab0`
* **示例：** `:reg "*`（查看系统剪贴板寄存器内容）。

## 2. 寄存器分类与深度解析

Vim 共定义了 **10 大类、共 48 个** 寄存器：

| 分类 | 标识符 | 读写权限 | 说明 |
| --- | --- | --- | --- |
| **无名寄存器** | `""` | 读/写 | 默认读写目标，同步最近一次的复制或删除 |
| **编号寄存器** | `"0` 到 `"9` | 读/只读（自动维护） | `"0` 保存最近复制；`"1`-`"9` 维护删除历史队列 |
| **小删除寄存器** | `"-` | 读/只读（自动维护） | 保存行内（少于一整行）的小幅度删除内容 |
| **命名寄存器** | `"a` 到 `"z` / `"A` 到 `"Z` | 读/写（大写追加） | 用户自定义寄存器，支持宏录制与文本暂存 |
| **只读寄存器** | `":`, `".`, `"%`, `"#"` | 纯只读 | 存储最后执行的命令、最后插入的文本、当前/轮换文件名 |
| **表达式寄存器** | `"= ` | 计算读取 | 动态评估 Vimscript 表达式 |
| **选择与剪贴板** | `"*`, `"+`, `"~"` | 读/写（依赖 GUI/X11） | 对应系统剪贴板与主选择区 |
| **黑洞寄存器** | `"_` | 只写/读空 | 静默丢弃内容，不影响其他寄存器（类似 `/dev/null`） |
| **最后查找寄存器** | `"/` | 读/写 | 存储最后一次搜索的正则表达式模式 |

---

## 3. 各分类详解、参数与实操示例

### 3.1 无名寄存器（The Unnamed Register: `""`）

* **标识符：** `"`
* **行为逻辑：** 任何未显式指定寄存器的 `d`、`c`、`s`、`x`、`y` 操作，都会默认将内容写入 `""`。执行 `p` 时默认也是从 `""` 读取。
* **使用示例：**
```vim
yy    " 复制当前行，内容同时存入 "" 与 "0
dd    " 删除当前行，内容覆写 "" 与 "1
p     " 等价于 ""p，粘贴刚被删除的行

```



### 3.2 编号寄存器（Numbered Registers: `"0` - `"9`）

#### 复制寄存器 `"0`

* **规则：** 专用于保存最近一次复制（yank）的文本。任何删除操作（`d`、`x` 等）都不会影响 `"0`。
* **解决痛点：** 解决了“复制了一段代码，中途删除了一个单词，导致粘贴出来的是删除词”的问题。
* **示例：**
```vim
" 1. 复制函数定义
yy
" 2. 移动到目标位置，顺手删除了多余的占位词
dw
" 3. 此时普通 p 粘贴的是 dw 的词，使用 "0p 则能正确粘贴 yy 的行
"0p

```



#### 删除历史队列 `"1` 到 `"9`

* **规则：** 保存所有**整行或跨行**的删除操作（Shift-in 循环栈）。
* 最新被整行删除的文本压入 `"1`。
* 发生新的删除时，原有内容依次顺推：`"1` $\to$ `"2` $\to$ `"3` $\to \dots \to$ `"9`，超过 9 的内容丢弃。


* **特殊重放机制：** 配合点号 `.` 使用时，Vim 会自动递增编号寄存器。
* **示例：**
```vim
"1p    " 粘贴最后一次删除的整行
u      " 撤销
.      " 自动执行 "2p（恢复倒数第二次删除的内容）
u      " 撤销
.      " 自动执行 "3p

```



### 3.3 小删除寄存器（Small Delete Register: `"-`）

* **规则：** 记录**不足一行**且未指定寄存器的删除操作（如 `dw`、`x`、`d$`、`ciw`）。
* **例外：** 如果显式指定了寄存器（如 `"adw`），则不会写入 `"-`。
* **示例：**
```vim
x      " 删除当前字符，字符存入 "- 与 ""
"-p    " 粘贴该字符

```



### 3.4 命名寄存器（Named Registers: `"a` - `"z` / `"A` - `"Z`）

* **规则：**
* **小写字母（`a-z`）：** 覆盖写入。
* **大写字母（`A-Z`）：** **追加写入（Append）**。写入 `"A` 相当于将内容附加在现有寄存器 `a` 的末尾。


* **典型用途：** 跨文件搜集代码片段、宏（Macro）录制。
* **示例 1（跨行收集并追加）：**
```vim
" 1. 覆盖写入第一段文本到寄存器 a
"ayiw
" 2. 移动到其他行，追加单词到寄存器 a
"Ayiw
" 3. 粘贴寄存器 a 的累积内容
"ap

```


* **示例 2（宏录制与执行）：**
```vim
qa          " 开始将按键序列录制到寄存器 a
0i// <Esc>  " 在行首插入注释符
q           " 停止录制
@a          " 执行宏
@@          " 重复执行最近一次宏
5@a         " 执行宏 5 次

```



### 3.5 只读寄存器（Read-only Registers: `".`, `"%`, `":`, `"#"）

此类寄存器不能手动写入，由 Vim 自动更新。

| 寄存器 | 内容与定义 | 示例场景 |
| --- | --- | --- |
| `".` | 上一次插入模式输入的文本 | 在普通模式输入 `".p` 重复粘贴刚输入的文本 |
| `"%` | 当前活动缓冲区的文件名（相对路径） | 在命令行输入 `:!chmod +x <C-r>%` 给当前文件加权限 |
| `":` | 上一次在命令行模式执行的 Ex 命令 | 输入 `@:` 重复执行上一条 Ex 命令 |
| `"#"` | 轮换文件（Alternate file）的名称 | `:edit <C-r>#` 切换回上一个文件 |

### 3.6 表达式寄存器（Expression Register: `"= `）

* **规则：** 允许在 Vim 中求值 Vimscript 表达式，并将计算结果作为输入插入文本或粘贴。
* **操作流程：**
1. 在 Normal 模式输入 `"= ` 或在 Insert 模式输入 `<C-r>=`。
2. 光标跳转到底部命令行，输入表达式并回车。
3. 结果将直接插入或可通过 `p` 粘贴。


* **示例 1（就地数学计算）：**
```vim
" 插入模式下输入：
<C-r>=1024 * 768<CR>
" 屏幕立即输出：786432

```


* **示例 2（调用内置函数）：**
```vim
" 插入当前时间戳：
<C-r>=strftime("%Y-%m-%d %H:%M:%S")<CR>

```



### 3.7 系统剪贴板寄存器（Clipboard Registers: `"*`, `"+`）

* **依赖前提：** Vim 编译时需包含剪贴板支持（运行 `vim --version` 必须显示 `+clipboard` 与 `+xterm_clipboard`）。
* **寄存器细分：**
* `"*`：**X11 Primary 剪贴板**（Linux 下的鼠标选区高亮，通常用中键粘贴）。
* `"+`：**系统剪贴板（Clipboard）**（Windows/macOS/Linux Desktop 的 `Ctrl-C` / `Ctrl-V` 剪贴板）。


* **使用示例：**
```vim
"+yy    " 将当前行复制到系统剪贴板（可在外部程序 Ctrl-V 粘贴）
"+p     " 从系统剪贴板粘贴外部内容到 Vim 中

```


* **全局参数绑定（无需敲 `"+` 的快捷配置）：**
* 设置 `:set clipboard=unnamedplus`，让默认的 `y` 和 `p` 自动重定向使用 `"+`。
* 设置 `:set clipboard=unnamed`，默认重定向使用 `"*`。



### 3.8 黑洞寄存器（The Black Hole Register: `"_`）

* **规则：** 类似类 Unix 系统的 `/dev/null`。任何写入该寄存器的内容都会被彻底销毁，**不产生任何备份，也不改变 `""`、`"0` 或 `"1**`。
* **解决痛点：** 替换当前单词时，删除旧单词不破坏刚复制的内容。
* **示例：**
```vim
yiw     " 复制当前单词（存入 "0 和 ""）
w       " 移动到要替换的目标词
"_diw   " 将目标词彻底丢入黑洞（保留了刚复制的 yiw）
P       " 干净地粘贴目标文本

```



### 3.9 最后搜索模式寄存器（Last Search Pattern Register: `"/`）

* **规则：** 存储最后一次通过 `/`、`?`、`*`、`#` 执行的搜索正则表达式。
* **高级技巧：** 该寄存器**支持写操作**，修改它会直接触发全局高亮，无需重新执行搜索。
* **示例：**
```vim
" 1. 查看当前搜索高亮的模式
:reg /
" 2. 批量将最近搜索的内容替换为 "target"
:%s/<C-r>///target/g
" 3. 手动通过 Vimscript 给搜索寄存器赋值以高亮显示某个词
:let @/ = "Error"

```

## 4. 寄存器的程序化读写（Vimscript API）

在编写 Vim 插件或自动化配置时，直接通过 API 读写寄存器是核心技巧：

### 4.1 函数接口

* **`getreg('{regname}' [, 1 [, 1]])`**：获取寄存器内容。
* 第二个参数为 1 时，返回表达式寄存器的真实字面文本而非计算结果。
* 第三个参数为 1 时，以 List 返回每一行。


* **`setreg('{regname}', {value} [, {options}])`**：向寄存器写入内容。
* `{options}` 参数控制写入模式：
* `'c'` 或 `'v'`：字符模式（Characterwise）。
* `'l'` 或 `'V'`：行模式（Linewise）。
* `'b'` 或 `"\<C-v>"`：块模式（Blockwise-visual）。




* **`getregtype('{regname}')`**：获取寄存器存储的文本布局类型（`v`、`V` 或 `^V`）。

### 4.2 语法糖（`@` 符号）

* **读：** `let text = @a`
* **写：** `let @a = "Hello Vim"`
* **追加：** `let @A = " 追加内容"`
* **清除寄存器：**
```vim
let @a = ""

```
